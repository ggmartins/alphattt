# Alpha Tic Tac Toe 

[![codecov](https://codecov.io/gh/ggmartins/alphattt/branch/main/graph/badge.svg)](https://codecov.io/gh/ggmartins/alphattt)

Reference implementation for a **FULL FLEDGED** ONLINE application featuring:

- Frontend (Angular, Auth TBD)
- Backend (Python/FastAPI main microservices, AI Stack Integration with .NET microservices, messaging, Expandable Staging)
- Observability (OpenTelemtry, fault-injection, tracebility)
- CICD/DevOps
- Agentic SRE

The first goal for this project is to have a *silly* small app like the "tic-tac-toe" as a **canonical** implementation to provide
baseline for more advanced reusable chain of tools like observability and AI engineering stack. The second goal is to use
this implementaion to exercise "swapable" components (aka decoupled architecture) and with minimal business rules / state machine for multiplayer
